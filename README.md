# Apendices_Tesis_Apis_mellifera_ACP
Apéndices del trabajo de grado: Predicción in silico de péptidos con potencial actividad anticancerígena derivados del genoma de Apis mellifera
## Contenido

| Apéndice | Descripción |
|---|---|
| A | Biblioteca peptídica inicial |
| B | Comparativa de clasificadores y recursos para ACPs (material suplementario adaptado de Wu et al., 2025) |
| C | Control de negativos para AntiCP2.0 |
| D | Resultados de AntiCP2.0 |
| E | Resultados de ToxinPred3.0 (modelos 1 y 2) |
| F | Resultados de mACPpred2.0 |
| G | Pruebas fisicoquímicas: secuencias, propiedades y código de análisis |
| H | Estructuras secundarias obtenidas con PHAT |
| I | Estructuras tridimensionales obtenidas con ColabFold (validación con AlphaFold3) |
| J | Diagramas de Ramachandran |
| K | Número de cortes registrados con PeptideCutter |
| L | Proceso de selección final: sistema multicriterio (numReq) y listado de los 25 péptidos seleccionados |
| M | Péptido control de Aminopeptidasa N |
| N | Resultados de HPEPDOCK 2.0 con Aminopeptidasa N |
| O | Resultados de PLIP |
| P | Resultados de xDeep-AcPEP para los cinco candidatos finales |

## Material complementario

- **Mucina:** Resultados de la interacción de cada uno de los candidatos finales con la mucina, obtenidos mediante HPEPDOCK 2.0.

Los archivos están en Excel, Word, PDF, TXT y cuadernos de Google Colab (.ipynb). Algunos apéndices están organizados en carpetas con varios archivos.
